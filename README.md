# Project-UART-IOT

Project IoT komunikasi UART menggunakan dua ESP32. ESP32-1 berfungsi sebagai sender yang membaca data suhu dan kelembapan dari sensor DHT11, kemudian mengirimkan data melalui komunikasi serial UART ke ESP32-2. ESP32-2 berfungsi sebagai receiver yang menerima dan menampilkan data suhu serta kelembapan pada LCD I2C.
